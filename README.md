# Приглашение под звёздами

Одностраничное приглашение на свидание: девушка открывает ссылку, за два шага выбирает
ужин и напитки, а ответ мгновенно приходит в Telegram приглашающему. Оформление — тёмное
звёздное небо и пергаментные панели с золотой филигранью, в духе интерфейсов Genshin Impact.

Стек: Vue 3 + Vite, без UI-библиотек. Отправка в Telegram — одна серверная функция на
Vercel. Деплой занимает пару минут, платить ничего не нужно.

## Как это работает

```
Браузер (Vue)  →  POST /api/notify  →  функция на Vercel  →  Telegram Bot API  →  твой чат
```

Токен бота живёт только в переменных окружения Vercel и в браузер не попадает никогда.
Клиент отправляет идентификаторы вариантов, а текст сообщения собирает сервер по своему
справочнику — подменить содержимое запросом нельзя. Свободный текст принимается в двух
полях, обрезается по лимиту и экранируется перед отправкой.

## Что видит гостья

| Экран | Содержимое |
| --- | --- |
| Титул | «Ужин под звёздами», кнопка «Открыть приглашение» |
| Шаг 1 · Ужин | 5 карточек: суши, салат, рыба, курица, суп. Суп раскрывает 5 вариантов (солянка, рассольник, рыбный, куриный, обычный). Либо карточка, **либо** своё поле на 300 знаков |
| Шаг 2 · Напитки | Сначала вид: с алкоголем или без. Дальше 4 карточки на выбор **либо** своё поле на 80 знаков |
| Проверка | Сводка ответа и кнопка «Отправить ответ» |
| Финал | Вспышка света, дата вечера и подпись |

На каждом шаге действует правило «одно из двух»: выбранная карточка стирает текст, введённый
текст снимает выбор карточки, а неактивная половина тускнеет, чтобы это было видно.

## Основные файлы

| Файл | Назначение |
| --- | --- |
| `src/App.vue` | Вся логика шагов и разметка экранов: состояние выбора, переходы, сводка, отправка |
| `shared/options.js` | Справочник для фронтенда: блюда, супы, напитки, лимиты полей, дата и время вечера |
| `api/notify.js` | Серверная функция: проверяет ответ, собирает сообщение и отправляет в Telegram. Свой справочник `CATALOG` внутри — намеренно, см. ниже |
| `src/components/StarSky.vue` | Звёздное небо на canvas: мерцание, дрейфующие частицы, падающие звёзды |
| `src/components/OrnatePanel.vue` | Панель-пергамент с золотыми уголками, которые прорисовываются при появлении |
| `src/components/ChoiceCard.vue` | Карточка выбора с ромбовидным сигилом и состоянием «выбрано» |
| `src/components/WishBurst.vue` | Вспышка с лучами на финальном экране |
| `src/styles.css` | Токены оформления: цвета, шрифты, кнопки, анимации переходов |
| `scripts/check-options.mjs` | Сверяет справочники фронтенда и функции, чтобы тексты не разъехались |
| `DEPLOY.md` | Шпаргалка по деплою и таблица частых ошибок |
| `check.sh` | Диагностика окружения: версия Node, наличие файлов и зависимостей |

### Почему справочник продублирован

Файлы вне папки `api/` могут не попасть в бандл функции на Vercel — тогда она падает целиком
с `FUNCTION_INVOCATION_FAILED`. Поэтому `api/notify.js` не импортирует ничего из проекта, а
список вариантов держит внутри. Меняешь варианты — правь оба файла и запускай `npm run check`:
скрипт сверит id, тексты и лимиты и покажет расхождение.

## Запуск локально

Нужен Node 18 или новее.

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173`. Все экраны и анимации работают, но **отправка в Telegram
недоступна**: `npm run dev` поднимает только фронтенд, серверных функций в нём нет. На шаге
отправки появится подсказка про `vercel dev`.

### С работающей отправкой

```bash
npm i -g vercel
cp .env.example .env     # вписать свои токен и chat_id
vercel dev
```

`vercel dev` поднимает фронтенд и функцию на одном порту, поэтому `/api/notify` отвечает
по-настоящему. Файл `.env` в репозиторий не попадает — он в `.gitignore`.

### Где взять токен и chat_id

1. [@BotFather](https://t.me/BotFather) → `/newbot` → скопировать токен
   (слово `bot` в него не входит).
2. [@userinfobot](https://t.me/userinfobot) → любое сообщение → вернёт числовой `chat_id`.
3. Открыть чат со своим ботом и нажать **Start**: боту запрещено писать первым.


## Что менять под себя

| Что | Где |
| --- | --- |
| Блюда, супы, напитки | `shared/options.js` и `CATALOG` в `api/notify.js`, затем `npm run check` |
| Дата и время вечера | `DATE_LABEL` и `TIME_LABEL` в `shared/options.js` |
| Лимиты свободных полей | `DINNER_CUSTOM_LIMIT`, `DRINK_CUSTOM_LIMIT` там же |
| Заголовки, подсказки, подпись | `src/App.vue` |
| Цвета и шрифты | `:root` в `src/styles.css` |
| Формат сообщения в Telegram | `api/notify.js` |
